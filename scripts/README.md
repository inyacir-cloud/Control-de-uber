# Scripts de Compilación

## build-apk.sh

Compila la app como APK nativo para Android.

**Requisitos previos:**
- Android Studio instalado
- JDK 17+
- ANDROID_SDK_ROOT configurado

**Uso:**
```bash
./scripts/build-apk.sh
```

**Nota:** Es más fácil instalar como PWA desde el navegador.
No necesita Android Studio y funciona en cualquier dispositivo.
